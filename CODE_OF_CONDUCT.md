# Code of Conduct

All Mycelium HA repositories follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work. Harassment, insults and personal attacks are not tolerated.

## Reporting

If someone violates this code of conduct:

- **Use GitHub's report function.** Every comment, issue and pull request has a **⋯ → Report content** menu, where you can report it to the repository's maintainers or to GitHub.
- **For anything you'd rather not report in public**, open a private report in the affected repository (**Security → Advisories → Report a vulnerability**) and start the title with "Code of Conduct". Only the maintainers can see it.

Reports are handled confidentially. Maintainers may edit or remove comments, lock conversations, and block people who violate this code.
