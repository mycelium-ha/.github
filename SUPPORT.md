# Support

- **Bugs:** open an issue in the repository of the affected integration, using the bug report template. Attach the diagnostics download.
- **Feature ideas:** open a feature request in the affected repository.
- **General Home Assistant questions:** ask in the [Home Assistant community forum](https://community.home-assistant.io/).
- **Security issues:** never open a public issue; follow [SECURITY.md](SECURITY.md).

These integrations are maintained in our spare time. We answer as soon as we can, but there is no guaranteed response time.
