# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any `mycelium-ha` repository, please **do not** open a public GitHub issue.

Instead, use GitHub's private vulnerability reporting feature (**Security > Advisories > Report a vulnerability**) in the affected repository.

Please include:
- Affected repository and version
- Steps to reproduce or proof of concept
- Potential impact

We will acknowledge your report as soon as possible and coordinate a fix before public disclosure.
